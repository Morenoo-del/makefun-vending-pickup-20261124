One pickup line, spoken by a vending machine to a passing human: a thousand strangers have pressed its buttons, but this one made its coils spin — so it waives the exact change and calls them a steal. Written for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty.

## The line

> I've dropped snacks for a thousand strangers, but you're the first to make my coils spin — press B7, exact change not required, you're already a steal.

## Run it

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt`.
